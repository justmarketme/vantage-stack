# ceo-coach MCP

CEO Coach & Strategic SOP Advisor MCP.

Exposes tools to:
- analyze existing SOPs against business goals + KPIs
- identify scaling bottlenecks and profitability risks
- recommend and generate new strategic SOPs for new initiatives
- link SOPs to KPIs
- compute goal progress + produce an executive CEO briefing (optionally sent to Telegram)

## Run

```bash
npm run mcp:ceo-coach
```

## Tools

- `analyze-sop-against-goals`
- `identify-scaling-gaps`
- `recommend-new-sops`
- `generate-strategic-sop`
- `link-sops-to-kpis`
- `create-sop-hierarchy`
- `track-goal-progress`
- `suggest-process-improvements`
